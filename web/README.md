# DRER web

A standalone Next.js App Router site for DRER, the cross-platform desktop agent in development. The original root `index.html` is preserved.

## Run locally

```sh
cd web
npm install
npm run dev
```

Open the address printed by Next.js. To use another port: `npm run dev -- --port 3100`.

## Production

```sh
npm run build
npm start
```

`npm run typecheck` checks TypeScript without emitting files.

## Structure

- `app/page.tsx` — route entry
- `components/home.tsx` — DRER content, menus, documentation search, clipboard actions, interactive product preview, FAQ, and walkthrough player
- `app/globals.css` — typography, responsive layout, transitions, scroll reveals, and reduced-motion behavior
- `public/fonts/` — the AWS Diatype, AWS Diatype Rounded Semi Mono, and Fragment Mono font files served by the reference site
- `public/media/drer-walkthrough.webm` — locally generated 14-second DRER illustrative workflow video

## Design and media

The visual reference is https://kiro.dev/: black background, rounded semi-monospace typography, restrained amber actions, cool charcoal product stage, overlapping terminal, alternating feature content, guide cards, questions, and a large closing panel. Fonts were obtained from the reference site's `/styles/fonts/` assets. The page does not embed Kiro scripts, tracking, product screenshots, or Kiro-branded demonstrations.

DRER artwork, the selectable agent sessions, voice waveform, calendar, app-building preview, and walkthrough are purpose-built illustrations. The page labels its demonstrations as illustrative; it does not boot a kernel or connect to an AI service. Source and setup links point to the real project. Desktop screenshot processing is described as cloud inference through Groq.

The page respects reduced-motion preferences. Video runs only after the visitor opens the walkthrough; terminal playback can be paused. Search opens with the search button or Command/Ctrl+K, and Escape closes the menus and dialogs.

DRER targets Windows, macOS, and Linux. Copy distinguishes the existing screen-aware Electron prototype from planned wake-phrase activation, calendars, reminders, recurring automations, vibe-building, and desktop actions. AuraOS is presented as the separate long-term research OS. The navigation uses the reference’s 13px/500 treatment, display headlines use the actual 700 font, and buttons use a 350ms rising oval fill.

The main demo has five selectable concepts: calendar planning, reminders, app building, recurring routines, and the existing screen-aware starting point. The app-building feature switches between code and an illustrative habit-tracker preview. Website interactions do not connect real calendars, create reminders, or control the computer.

The feature explorer follows the bounded section of https://antigravity.google/ from the agentic-platform introduction through its SDK row: an undulating circular icon strip with scroll-linked horizontal travel, a large typed introduction, four generously spaced rows, square rounded media panels, and descriptions that reveal glyphs on entering the viewport. The DRER version keeps the charcoal palette, original brand fonts, and its own interactive concept visuals. The icon wave pauses offscreen, text has a screen-reader equivalent, and reduced-motion preferences disable the motion.

## Navigation and dedicated pages

The shared header and footer live in `components/site-header.tsx` and `components/site-footer.tsx`. The navigation links to actual pages, with product and resource disclosures, active destinations, mobile navigation, and cross-page search. `lib/site.ts` defines the navigation directory.

Twelve dedicated routes are statically generated by `app/[slug]/page.tsx`: `/agent`, `/products`, `/desktop`, `/automations`, `/build`, `/platforms`, `/docs`, `/roadmap`, `/community`, `/resources`, `/auraos`, and `/get-started`. Each has its own metadata, content, and appropriate demos or guide structure. `lib/page-data.ts` contains the page content; `components/detail-page.tsx` renders the editorial layouts. `components/page-interactions.tsx` contains workflow examples, platform-specific setup instructions, and copy actions.

The new navigation and page direction reference https://x.ai/ and its product, build, API, and company information architecture. Direct visual inspection was blocked by that site's browser access controls; its readable page content informed the grouped navigation and dedicated product pages. No x.ai branding, enterprise features, pricing, release claims, or fabricated accounts are included. The existing homepage typography and feature explorer remain intact.
