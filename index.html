02 / Under the surface

AI belongs in the
conversation.
And in the architecture.

AuraOS is a 32-bit x86 research project. Its AI core lives alongside the memory manager, interrupts, and drivers, collecting context before handing a question to the inference backend.

Groq inference runs through a host-side serial proxy. Without an API key, the kernel uses a built-in mock responder.

A few things to know

A little clarity before you dive in.

Is AuraOS ready to replace my everyday operating system?

AuraOS is an experimental kernel project for learning and exploration. Run it in QEMU. Features such as a process scheduler, filesystem, and networking stack remain on the roadmap; it is not a complete everyday desktop OS.

How are AuraOS and AuraAI different?

AuraOS is the experimental x86 operating system. AuraAI is a separate Electron companion that runs on your existing desktop and provides a screen-aware overlay. You can explore either project independently.

Does my screen stay on my device?

The desktop companion sends a captured screenshot to Groq for analysis when you invoke it. It requires your Groq API key. The kernel integration sends collected system context through a host-side serial proxy; it can also run a built-in mock responder without a key.

Can I try the assistant on this page?

The preview above is an illustration with switchable views. To run the real kernel or companion, follow the kernel setup guide or the AuraAI instructions.
